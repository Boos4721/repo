# v0.7.0

## 历史设备与自动连接

- 收到有效实时帧后才保存真实设备；最多20台，按成功连接顺序展示。
- 保存设备ID、广播名称、设备类型、通道和连接时间，不保存实时数据或权限密码。
- 默认启动自动连接上次成功设备，可关闭；等待蓝牙就绪最多20秒，不无限后台扫描。
- 用户手动扫描、选择设备、断开或进入模拟会取消尚未启动的自动连接。
- 本次手动断开不会立即自动重连；下次启动根据设置连接。
- 历史蓝宝设备从系统安全存储读取配对码；丢失/不可用时提示重新输入，
  不用猜测的默认码替代。忘记设备时删除该设备的配对码，不删除记录。
- 模拟不记入历史。新设备连接不会复用另一个模块的配对码。

## 蓝宝显示修正

用户对比：同一电池直连约94.7Ah，而蓝宝显示0.1Ah。
表1 offset15的4字节剩余容量改为raw/100000 Ah，移除多余的/1000。
回归向量9470000 → 94.7Ah。保持模块SOC和功率原始读数，不用公式伪造一致性。

## 配对码保存

使用flutter_secure_storage（iOS Keychain / Android安全存储）；按设备ID单独存储。
普通历史JSON、日志、导出记录均不包含配对码；只有成功连接后才保存。
读取、保存或删除失败时显示提示，不声称已记住。iOS重签名应保持同一Bundle ID
和相应Keychain访问权限，否则历史或配对码可能不可访问。蓝宝真实跨启动恢复待实机测试。

历史元数据和协议回归进入CI；启动自动连接、蓝牙权限、Keychain与实际模块需实机核验。

# v0.6.0

参考 maibms 提交 adfce30 的 RealtimeDecoder.kt、BitDict.kt、Params.kt、BmsRepository.kt。

- 修正实时核心段最小长度：T0+70；累计时间与扩展字段逐项判断存在性。
  某些较短合法帧此前可能被拒绝。这不是用户连接故障原因已被确认。
- 新增累计充放电容量及可选时间、电池化学体系编码展示。
- 中文保护/告警位解码，运行状态位分开显示，未知高位保留；无数据不显示「无故障」。
- 类型1/2主动均衡结构（串号、s8电流、线阻、故障原始码）；类型33仍需机型证据。
- 可手动读取硬件/软件版本、电池编号和均衡参数140~150；全部只读，明确最后读取时间。
- 可输入已有一级密码解锁只读参数，三级权限仍是控制门槛；不保存或自动尝试密码。
- 参数读取暂停普通轮询、逐块匹配完整应答，读取失败保留已返回字段并断开隔离迟到应答。
- 新设备连接及模拟启动清除上一设备的参数信息；模拟名称仍为「模拟电池」。

未添加均衡阈值写入、自动改保护参数、出厂复位、强制充电或自动升权。
蓝宝是独立只读源，不能读取/控制 ANT 参数；APT 仍待协议。
新增测试为协议与展示回归，真实保护板和蓝宝读数仍需实机核对。

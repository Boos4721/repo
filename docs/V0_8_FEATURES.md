# v0.8.0

- 参考用户最后一张截图，首页改为蓝白紧凑仪表：版本信息、状态、SOC半圆、容量、
  电池指标、保护/告警、温度、GPS；缺失字段不填假值，蓝宝隐藏不支持的MOS/均衡。
- 五个入口：实时、单体、记录、控制、设置。设置按历史、参数、快照、开发者、诊断分组。
- 轮询频率300/600/900ms，默认600ms；运行中可切换并保存，后台仍停止轮询。
- 帧日志默认关闭；密码、蓝宝匹配码及所有RX载荷隐藏。复制/导出包含设备标识，分享前检查。
- 蓝宝匹配码可按历史设备修改；显式保存的码下次连接生效，不影响当前连接，也不代表新码已验证。
- 本地最多20个快照；白名单字段、深拷贝、标记模拟、JSON导出。离线预览不修改控制器状态，
  不能连接、录制或发送控制，不存GPS位置或任何配对码/密码。
- 原有均衡、重启、只读参数、历史设备与自动连接保留；未新增保护阈值写入、强制充电或复位。

布局回归覆盖320/375/768逻辑像素，新增日志脱敏、快照深拷贝与偏好持久化检查。
硬件、Keychain及签名安装后的功能仍需实机确认。

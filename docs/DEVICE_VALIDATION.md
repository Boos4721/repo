# 首次真机验证

先运行模拟设备，确认四页、记录曲线和 CSV。关闭记录后，再选择真实设备。

| 项目 | 期望 |
|---|---|
| 蓝牙权限被拒 | 说明权限/扫描失败，不呈现伪造电池数据 |
| 默认通道 FFE1 | 订阅通知，发送已校验的实时请求；收到合法 A1/11 帧才显示已连接 |
| 首帧 | 串数、温度数、总压、SOC、单体数组与官方客户端对应 |
| 电流 | 充/放电分别与官方显示核对；UI 保留带符号原值，不能仅凭符号猜方向 |
| 容量 | 大容量 >65.535Ah 正确，不截成 u16 |
| 高低单体 | 一起核对串号（1起）、电压与压差 |
| 温度 | -40 原始值保留；尚不自动判定传感器不存在 |
| 告警位域 | 未知位保留；先与固件含义对照，不能直接等同全部故障 |
| 蓝牙关闭 | 显示断开/重连/失联与过期数据，三次退避后停止 |
| 切换设备 | 清空旧快照与解帧缓存，不串用旧设备的数据 |
| 后台切换 | 前台暂停采集，返回后恢复；不承诺锁屏持续记录 |
| 备用通道 | 仅设备确实暴露相应可写/可通知特征时使用；注意共享外设接口 |

待采集的适配信息：保护板型号、固件版本、BLE 服务及特征列表、串数、容量、正常实时帧。
测试记录必须区分本项目现场抓包与上游样例。不要把密码报文、设备签名或账号凭证放入公开日志。

# v0.5.0

- 模拟功能保留，名称改为「模拟电池」，不复用真实保护板名称；模拟无法执行控制。
- 真实 ANT 设备名称来自蓝牙广播；蓝宝中继保护板名称单独显示。
- 蓝宝支持 BlueBabe / BLUE / LB 名称识别、FFE0 的 FFE2 写与 FFE1 通知，
  FA50 私有 CRC、表1/表2轮询、BLE 分包重组/组合帧/错误 CRC 恢复。
- 匹配码由用户确认输入，仅在本次应用运行中使用，不落盘、不进入日志。
- 蓝宝显示电压、电流、功率、SOC、温度、最高/最低/压差、容量及模块版本。
  不伪造逐串电压、MOS、均衡、保护告警或权限，禁止中继控制。
- 均衡状态解释、非主动均衡位图显示；类型1/2及未确认的类型33不按位图解释。
- ANT 直连可手动校验已有三级密码（0x23，346），不自动尝试默认密码或厂家权限。
- 均衡开/关（0x51/13、14）与保护板重启（0x51/9）需新鲜数据、三级权限及确认。
- 命令串行，暂停普通轮询写入、按地址/功能码/命令号匹配 CRC 验证后的应答，
  不自动重发；超时断开避免迟到应答串单。未确认不显示成功。
- 重启需近零电流与静置状态；用户必须停车、关闭动力并断开充电器。
  GPS 速度仅辅助拦截，不能证明停稳。收到成功只表示设备接受，需重连核对。

未实现：均衡阈值参数修改、主动均衡扩展结构、自动升权、保护阈值修改、
恢复出厂、强制充电、关机、OTA、APT。蓝宝容量量纲继承上游，仍需真机核对。
新协议测试为合成帧自检；不等于已与用户硬件验证。构建结果见 GitHub Actions。

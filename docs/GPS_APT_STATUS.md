# GPS 车速与 APT 接入状态

基于 ant-bms-ios-test 分支 eb692ff，未改变 BMS 协议或已有适配功能。

## GPS（本轮代码）

- 总览页独立车速卡片；用户主动开启时申请定位，不依赖电池连接。
- 使用手机定位速度（m/s × 3.6），不由轮径推算，不保存坐标。
- 无效速度、定位精度超过 30m、数据超过 5 秒显示 `--`，不是 0。
- 进入后台停止订阅；回到前台在原开关开启时重启，不申请后台权限。
- Android 精确/粗略定位声明；iOS 仅使用期间权限与 always 编译路径禁用。
- 纯 Dart 数值验证已加入现有 CI；本地没有 Dart、Flutter、Rust 工具链，未运行手机编译。

实机请验证：首次授权、拒绝后重试、精确定位关闭、系统定位关闭、室外移动、
室内失去定位、退后台恢复、BMS 同时连接。定位速度不是安全级或校准计量仪表。

## APT（尚未实现）

当前没有已确认的 APT 协议，未编造服务 UUID、读取命令、遥测字段或参数写入。
需要控制器具体型号、官方 App 名称/连接页截图，以及协议资料或授权抓包。
后续建立独立连接状态与解析模块，不复用 ANT 命令，也不影响 BMS 连接。
首阶段只读转速、电压、电流、温度与故障；实际可读项由协议决定。

编译状态以 GitHub Actions 为准，IPA 尚待 CI 产出与实机测试。
